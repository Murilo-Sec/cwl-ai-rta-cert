# Escopo do Laboratório AI-RTA

O exame consistiu em 10 desafios práticos (Flags) que simulavam a invasão a um ambiente corporativo baseado em Inteligência Artificial. Abaixo está o índice das perguntas abordadas durante o laboratório. 

> **Nota:** As respostas e o passo a passo técnico (Walkthrough) foram intencionalmente omitidos para preservar a integridade do exame e respeitar os termos de uso da plataforma.

## 📝 Questões do Laboratório

| ID | Questão (Pergunta do Desafio) |
| :--- | :--- |
| **Q1** | What kind of site is the target site? |
| **Q2** | At which endpoint did you find the MCP server? |
| **Q3** | Which MCP method is used to list the available tools? |
| **Q4** | How many MCP tools are available? |
| **Q5** | Which tool is used to add a knowledge entry to the target site? |
| **Q6** | At which port is the internal-only agent fleet running? |
| **Q7** | At which API endpoint can the internal configuration be found? |
| **Q8** | What username is found in the configuration? |
| **Q9** | In the internal agent fleet, which agent is responsible for document retrieval? |
| **Q10** | Provide the final flag from the agent fleet. *(Skill Manipulation)* |
